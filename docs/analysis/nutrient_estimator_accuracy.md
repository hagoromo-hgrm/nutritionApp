# 栄養素推計の精度評価

- 評価日: 2026-07-26〜2026-07-28
- 対象: ブラウザ内推計 `browser-rule-0.2.0`〜`browser-rule-0.13.0`、Python検証コア `0.2.0`
- 対象栄養素: 飽和脂肪酸、食物繊維、カルシウム、鉄、ビタミンA・E・B1・B2・C

## 1. 評価データ

実商品の非公開配合を推測して正解扱いしないため、今回は人工配合による内部整合性を評価した。

- ブラウザ版の同条件比較: MEXT生成物から独立転記した13食品の100g値を使い、原材料表示順を満たすクッキー・ビスケット12配合を作成した。
- ブラウザ版の境界拡張評価: 参照を17食品、配合を15件へ増やし、曖昧な植物油脂、商品名事前確率、`ゆず砂糖漬け（ゆず、砂糖）`、`／`以降の添加物を含めた。
- Python版: 推計コアのMEXT参照プロファイルを使い、原材料表示順と各プロファイルの配合範囲を満たす15配合を作成した。
- 正解値: 真の配合比と参照食品の100g値から合成した。
- 推計入力: 正解の対象9栄養素は隠し、熱量は整数、たんぱく質・脂質・炭水化物は0.1g単位、食塩相当量はブラウザ版0.1g・Python版0.01g単位へ丸めた。
- 欠損: 参照値の`null`を0へ変換せず、推計結果も`unavailable`または対象キーなしになることを正解とした。
- 再現性: 固定fixtureと決定的な探索を使用した。

参照版は[文部科学省「日本食品標準成分表（八訂）増補2023年」](https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html)である。食品成分値の意味と表示上の丸めは[食品成分データベースのヘルプ](https://fooddb.mext.go.jp/help.html)を参照した。テストへ値を転記しただけで、外部データベースをアプリへ追加同梱していない。

## 2. 指標

- MAE: 絶対誤差の平均
- MAPE: 正解が0ではない項目の絶対パーセント誤差の平均
- 推定範囲包含率: 正解値が表示範囲の最小値以上かつ最大値以下だった割合
- availability/null整合率: 正解値の有無と推計可否が一致した割合

MAPEは正解値がごく小さい場合に大きくなりやすいため、MAEと併記する。栄養素をまたいだ全体MAPEは単位差を平均した参考指標である。

## 5. 評価の限界と次の改善

この結果は、推計側と同じMEXT食品プロファイルから合成した人工配合に対する内部整合性であり、実商品の精度を示さない。次はメーカーが対象栄養素を公表している商品を、学習・調整に使わない固定検証セットとして追加する必要がある。

特に次の差は今回の人工データへ含めていない。

- 原材料名と参照食品の不一致、および今回の代表例以外の複雑な複合原材料・添加物
- 品種、製造条件、水分変化、原料ロットによる成分差
- 加工・保存によるビタミン等の損失
- 実商品ラベルの丸め幅と分析誤差
- 曖昧な「植物油脂」「乳等を主要原料とする食品」の候補分布
- 商品名から作った事前確率の実商品に対する校正

実商品セットを得るまでは自動採用を行わず、参考値、範囲、信頼度、警告、手動採用という現行の安全策を維持する。

## 6. メーカー公式値による実商品評価

2026-07-28の更新後データは、アサヒ飲料、BASE FOOD、ブルボン、コモ、フジッコ、伊藤ハム、キユーピー、丸大食品、明治、森永製菓、ニチレイフーズ、日清食品の公式サイト由来2,636行である。原票はGitへ含めず、`scripts/build_spu_estimator_training.py`で次の条件を満たす779件へ正規化した。ファイル名は右端の`_{source}_{YYMMDD}`から解析するため、`asahi_milky`のようにメーカーキーにアンダースコアを含められる。任意の`製品URL`列があれば商品単位の出典として保持する。

- 明示的なg基準を栄養表示と対応付けられる
- 原材料と主要5栄養値がある
- 9対象栄養素のいずれかがある
- 複数商品の値をスラッシュで併記した行ではない
- 「推定値」は保持するが独立正解から除外する

主な除外は、明示的なg基準なし931行、対象栄養素なし827行、食塩相当量なし34行、エネルギーなし19行、重複14行、原材料なし13行、栄養表示なし11行、複数商品併記6行だった。メーカー分類は直接使用せず、商品名、メーカーカテゴリ、原材料の順でアプリのジャンルへ再分類した。メーカーと容量・味違いを正規化した商品系列を組にして、545件を学習、128件を校正、106件を最終テストへ固定した。

`browser-rule-0.10.0`では、一般カタログを210プロファイル・479別名・16分類へ拡張した。FDC SR Legacyの直接値はココアバターに加え、小麦ふすま、ココナッツ油、鶏脂、酵母エキススプレッド、種子ガムの計6件とした。麦芽糖、エリスリトール、パラチノース、L-カルニチン、ガラクトオリゴ糖、ミルクミネラルは原料メーカーまたは業界団体の公式仕様を採用し、適用できる形状、規格から確定できない欠損、代理参照を警告に残す。酵母エキスはFDCスプレッドと水分40.9%からの乾物換算、パネトーネ種はコモ公式説明を根拠に乾燥・圧搾酵母を離散候補にした。

原材料を確認できる2,577商品で、`browser-rule-0.9.0`を更新データへ適用した値を比較基準にした。全原材料を解決できる商品は1,088件（42.220%）から1,498件（58.130%）へ410件、15.910ポイント増えた。未解決原材料の出現数は3,129件から1,777件へ43.209%減少し、未解決の異表記数は1,016から901へ減った。括弧・亀甲括弧・引用符付き区画に加え、`【ミックス】…【ソース】…`のような隅付き括弧見出しを区画境界として解析する。集計値は`docs/analysis/spu_ingredient_coverage.json`へ保存する。

ビタミン、カルシウム、鉄、食物繊維へ寄与し得る添加物が表示されている場合は、配合量を真の0とはみなさない。`browser-rule-0.11.0`では、原材料の一部だけを解決できる商品について、未解決原材料の重量枠を表示順の仮配合へ残し、既知原材料の寄与だけを低信頼度の部分参考値として追加した。既知原材料だけを製品重量100%へ再配分せず、部分参考値は商品の保証下限でも商品全体の上限を持つ範囲でもないことを画面へ表示する。

最終テスト219区間では、全原材料推計44区間と部分参考値91区間、合計135区間（61.64%）を提示できた。部分参考値91区間の79.12%は公表区間の上限以下、点推計区間内率は19.78%、範囲重複率は51.65%、MAPEは44.11%だった。この結果からも「最低限これだけある」と保証できる値ではなく、未解決分を含まない参考値として区別する必要がある。部分参考値は実測校正から除外し、全原材料推計だけで校正可否を判定する。校正分割では各栄養素の全原材料推計が30件未満のため、実測校正は採用せず、`sampleSize=0`、`scope=fallback`の暫定範囲を維持する。商品単位の結果を除いた再生成可能な集計は`docs/analysis/spu_estimator_evaluation.json`に保存する。

`browser-rule-0.12.0`では、参照値欠損と添加物寄与割合不明でも数値を確認できる原材料分を部分参考値として返す。全1,551区間のうち通常推計315、部分参考値1,229、合計1,544区間となり、数値提示率は99.55%で目標80%を通過した。推計不可は7区間・3商品で、すべて参照できる原材料がない`原材料未解決`だった。

最終テスト219区間では通常推計43、部分参考値175、合計218区間へ数値を提示した。部分参考値の点推計区間内率は18.29%、公表上限以下85.71%、範囲重複率44.00%、MAPE47.59%である。数値提示率と高精度推計率を混同せず、部分参考値は低信頼度・手動採用・理由表示を維持し、全原材料推計だけを実測校正へ使用する。理由別・栄養素別・ジャンル別の対策優先順位は`docs/analysis/nutrient_estimator_availability.md`に記録する。

`browser-rule-0.13.0`では、学習区分545商品のメーカー公式表示から100g当たりのジャンル階層型5・50・95パーセンタイルを生成した。ジャンル中央値を未確認寄与として既知分の点推計へ加える試行は独立テストで誤差を悪化させたため棄却し、既知分の点値を維持して事前分布を推定範囲だけへ使う。数値を直接参照できる原材料が1件もない場合だけ中央値を低信頼度参考値にする。

全1,551区間では通常推計315、既知分部分参考値383、ジャンル補完参考値853となり、数値提示率は100%になった。最終テスト219区間の方式合計は、点推計区間内率24.20%、公表上限以下85.39%、範囲重複率58.45%、MAPE49.42%だった。`browser-rule-0.12.0`の方式合計に比べ、範囲重複率は49.54%から8.91ポイント改善し、点推計区間内率は24.31%から0.11ポイント低下、MAPEは49.34%から0.09ポイント上昇した。ジャンル補完単独123区間では範囲重複率65.04%、MAPE49.27%である。これは分離重量の推定精度ではなく、広いジャンル分布を使った参考範囲の評価であり、実測校正から除外する。

残る上位未解決は、キャリア組成が不明なビフィズス菌液、内訳だけでは評価できない`具`・`衣`・`たれ`、濃縮率が不明な果汁、加工肉・ペースト・粉末ソース等である。これらを名称だけで単一食品へ寄せると可用率は上がるが精度を悪化させるため、今回は未解決を維持した。飽和脂肪酸、鉄、ビタミンはジャンル・メーカーの偏りも残る。次の追加データは、同じジャンル・栄養素で30件以上の推計可能例を確保し、特に栄養添加物に依存しない商品、飽和脂肪酸表示商品、現在少数のパン・惣菜を別メーカーから増やす必要がある。
