## 解釈と再現

- 正値MAPE・ゼロ件数・bias・p90/p95・点値区間内率・区間重複率・表示基準量の指標・ジャンル別・paired差は同名JSONに保持。範囲表示の中間点は真値にしない。メーカー表示は分析真値ではなく、区間重複を真値包含率とは呼ばない。
- 完成配合、加工前後重量、添加物doseの証拠は本集合にない。その経路の検証は専用の計算/保存テストであり、この結果から実商品精度を主張しない。
- 旧教師priorはlegacy_unreviewed。hash整合を確認したことと、ラベル/系列を人が全レビューしたことを区別する。
- 初回監査は除外情報の再シリアライズされたコピーをbyte hash不一致で拒否した。元の封印除外ファイルのhash一致を確認してパスのみを修正し、モデル/評価器/係数は変更せず再実行した。初回は推計未実行。
- freeze JSONのSHA/hashと事前手順は `nutrient_estimator_evaluation_freeze.json` / `nutrient_estimator_evaluation_protocol.md`。個票と公式原票はprivateに残しGit/PWAへ含めない。

後続の精度改善は新しい校正系列・確認済み製剤/配合資料・教師の人的監査を使い、ここで開封した30系列を未見集合として再利用しない。
