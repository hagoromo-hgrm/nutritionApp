# 固定モデルの未見評価手順

2026-10-04。未見ラベルを開く前に本手順・評価器・最終モデルをcommitし、そのcommit SHAとファイルhashをfreeze JSONへ固定する。個票・商品名・原票・URLは公開しない。評価後にこの集合で係数・候補・モデルを調整しない。

## 比較するモデルと入力

- 変更前: commit `2e904ffdd1508c7a63e4e87d13603b5a6ba30716`、browser-rule-0.21.0。Git archiveから抽出したモデルを利用し、比較前に抽出ファイルのhashも検証する。
- 最終: browser-rule-0.32.0。既定legacy_point、飽和脂肪酸feedback 0 / postBlend .75。本番の候補・比率予算をそのまま使う。
- 評価集合: 事前封印の30商品/30系列。全件testで系列を重複させない。取得後の取捨選択を行わない。
- 各商品の対象栄養素を1つずつ要求し、対象自身のラベルを入力から外す。非対象の非推定メーカー表示を同じ要求へ渡す。追加栄養入力を利用できない旧モデルとの差は、この機能を含む最終モデルの比較である。
- 旧モデルと最終モデルで同じ要求ID、原材料、表示基準量、商品名、ジャンルを使う。基準量を出力の100gに置換しない。通常の商品表示には完成配合・加工重量・添加物doseの明示証拠がないため、その新経路の実商品精度を本集合から主張しない。

## 指標と分類

固定表示と範囲表示を受け入れ、推定表示を対象参照から除外する。固定表示は表示点値に対するMAE・signed bias・p90/p95絶対誤差を計算する。100g換算とパッケージ表示基準を別々に報告し、栄養素間で平均しない。正値だけのMAPEとその件数、ゼロ表示の件数を示す。範囲表示の中間点を真値にはしない。

現行CAA区間に対する区間外MAE、点値が参照区間内にある率、推計区間との重複率、推計範囲平均幅を別に示す。区間重複を真値包含率とは呼ばない。メーカー表示は分析真値ではなく、CAA許容区間も推計の保証区間ではない。

全原材料、既知分のみ、ジャンル参考を方式別に集計し、栄養素別・ジャンル別の件数とavailabilityを記録する。両モデルが推計できた同じ参照に限定したpaired MAE差・区間外MAE差・幅差も示す。availabilityの増減と方式変更件数を別に記録する。方式別集計は各方式の対象集合が異なり得るため、それだけで改善を断定しない。

大誤差は100g換算の固定点絶対誤差が `max(絶対床, 表示点の絶対値×2)` を超える場合と事前定義する。絶対床は飽和脂肪酸/繊維2g、Ca100mg、Fe1mg、A100μg、E1mg、B1/B2各0.1mg、C10mg。これは診断基準ではなく比較用閾値である。

## 独立支持と監査

栄養素ごとに独立30系列以上、3メーカー以上、最大メーカー占有50%以下を形式的支持の必要条件とする。封印集合は全9対象で30系列未満であるため、精度確立・全項目改善・保証率を主張しない。1～4参照しかない栄養素の数値は特に探索的な記述に留める。

モデル/評価器hashを確認してから封印ファイルを読む。封印元bytes・Python canonical hash・manifestのID/系列/genre/test全単射・除外集合hashを再検証する。教師は別にsource/canonical/manifestを検証し、現行priorの出典hashと照合する。bytes整合は人的確認とは区別し、旧教師のlegacy_unreviewed状態を報告へ残す。

再実行にはfreezeに記録したcommitと同一bytes、非公開の封印/教師データ、旧commitのarchiveが必要。CLIは `node scripts/run_frozen_nutrient_evaluation.mjs`。リリース後のHEADではfreezeを更新せず、該当commitを再現する。公開JSONは集計のみで個票を含まない。
