# 推計原材料プロファイルの加工状態監査

監査日: 2026-10-03  
照合対象: `src/services/nutrientEstimatorProfiles.ts` と `data/mext/processed/mext_foods.json`

候補の意味と警告が変わるため、推定結果の記録に使うブラウザモデル版を `browser-rule-0.22.0` に更新した。推計アルゴリズム自体は変更していない。

## 結果

加工状態が異なる原材料を単一のMEXT値へ無警告でまとめていた別名を分離した。MEXTは可食部100gあたりの標準成分値を食品項目ごとに掲載しているため、食品名が示す状態が違う場合は別の項目を使う。

| 原材料名 | 変更後の参照 |
| --- | --- |
| 粉あめ | MEXT `mext_03015` の直接値 |
| 還元水あめ | MEXT `mext_03032` の直接値。脂質と飽和脂肪酸の欠損を維持 |
| 水あめ（酵素糖化） / 水あめ（酸糖化） | 各MEXT直接項目 `mext_03024` / `mext_03025` |
| 糖化法が書かれていない水あめ | 酵素糖化・酸糖化を曖昧候補として提示し、糖化法の違いを警告 |
| 無発酵有塩 / 無発酵食塩不使用 / 発酵有塩バター | 各MEXT直接項目 `mext_14017` / `mext_14018` / `mext_14019` |
| 一般名のバター、塩や発酵状態が一部だけ明示されたバター | 対応し得るMEXT項目を曖昧候補として扱い、特定できない状態を警告 |
| バターオイル、バター加工品 | MEXT直接項目なし。無発酵有塩バターを低信頼度の代理候補として表示し、濃縮度・配合の違いを警告 |
| 卵粉、全卵粉、乾燥全卵 | MEXT `mext_12009` の乾燥全卵へ直接対応。生卵候補を除外 |
| 卵黄・卵白 | 生の卵黄 `mext_12010`・卵白 `mext_12014` に対応。生と明記された場合だけ無警告の直接候補にし、状態が不明な場合は警告を付ける |
| 卵白加水分解物 | MEXT直接項目なし。乾燥卵白を低信頼度代理として警告 |
| 粉末しょうゆ | MEXT直接項目なし。液状こいくちしょうゆの代理を低信頼度とし、濃縮度と賦形剤量が不明なことを警告 |
| デキストリン | 商品名の「食物繊維」等から粉寒天候補を選んでいた経路を削除。通常デキストリンは、従来どおり、でん粉由来の低信頼度代理候補を使う |

脂質0gから飽和脂肪酸0gを導出する既存ルールは維持した。MEXT元データでは `mext_03015`、`mext_03024`、`mext_03025` の飽和脂肪酸は欠損だが、推計プロファイルでは0gとし、`MEXTの脂質が0gのため、飽和脂肪酸を0gと導出しています。` を残す。これは元データの値ではなく導出値である。脂質が欠損の `mext_03032` は、飽和脂肪酸も欠損のままにした。

手動で転記している直接プロファイルは、監査対象の食品番号について生成済みMEXT値とテストで照合する。脂質0gの糖類3件だけは上記の明示的な導出を除き一致し、粉あめ・バター類・卵類の直接値は一致する。代理候補には元食品番号を出典として保持し、`ambiguous` と具体的な `derivationWarnings` を付けた。

この作業では乳原料全体の再分類は行っていない。既存の「脱脂濃縮乳」代理は引き続き警告付きであり、一般名「粉乳」の別名は追加していない。
