# 同候補の複数配合と材料規格の境界

2026-10-04、モデル0.31.0。点値は従来の最良配合を維持する。同じ決定的探索で得た表示順制約内の配合から、最良目的関数との差4以内かつ既存比率とのL1距離.02以上の最大3配合を範囲へ追加する。候補ごとに成立したシナリオ数kでpriorを分割し、候補数と配合数を区別する。最大12サンプルだけを一時保持し、範囲への採用は最大4/候補。候補64組の上限・乱数サンプル数は増やさない。

traceには候補ID、実比率、score、priorShareを保存する。新policyのbackupは最大256シナリオ、候補内share合計1、同一候補最大4、表示順と比率合計を検証する。旧policy無しtraceへ緩和を適用しない。暫定5〜95%加重分位点は実商品90%真値包含の検証結果ではない。

[ADPI Milk Minerals Standard v2.0](https://www.adpi.org/wp-content/uploads/2023/07/Milk-Minerals-Standard-v-2.0_2023.pdf)のCa22%以上は適合材料の最低含有率であり、一般名「乳清ミネラル」から適合性・gradeを確認できない。一般名の点値はnullとし、規格境界は条件付きmetadataに分離する。物理的質量上限や平均から確定Caを作らない。

[松谷化学の製品重量基準資料](https://www.matsutani.co.jp/product/kinousei/topix02/)はFibersol2の繊維85%以上を示す。[米国製品資料](https://fibersol.com/about-fibersol/products)の乾物基準と区別し、一般名の難消化性デキストリン・イヌリン等へ同じ製剤規格を適用しない。粉寒天代理のPFC/繊維値を未知carrierの確認済み値として使わずnullを維持する。

実製剤と添加量が確認された場合はv3明示添加物根拠のminimum/rangeを使用できる。通常検索の一般名だけから材料の最低値、純度、添加量や保証上限を作らない。合成テストによる決定性・保存往復と実商品の精度は別に扱う。
