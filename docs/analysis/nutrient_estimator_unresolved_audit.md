# 栄養推計の高頻度未解決語・加工状態監査

2026-10-03 時点の推計辞書を、原材料名の加工状態と日本食品標準成分表の収載状態に照らして確認した。対象は乳・乳たんぱく、昆布・昆布エキス、濃縮果汁、具・衣、オニオンパウダーである。原材料名だけで特定できない加工状態や濃縮度を数値補完せず、代理候補には警告を付け、対応する根拠がないものは未解決に残した。

## 未解決頻度の基準

基準データ [`spu_ingredient_coverage.json`](spu_ingredient_coverage.json) は `browser-rule-0.12.0`、2,577商品を集計し、完全解決1,498商品（58.13%）、未解決1,777出現、未解決語901種類を記録している。以下は同ファイルの未解決語頻度であり、この監査後の推計結果や改善効果を示す値ではない。

## 受け入れた対応

| 語群 | 対応 |
| --- | --- |
| 乳製品・乳等を主要原料とする食品・乳 | 液状の普通牛乳、全粉乳、脱脂粉乳、乳脂肪クリームを異なる加工状態の候補として返し、すべてに状態不明の警告を付ける。牛乳・全粉乳・脱脂粉乳の明示名はそれぞれ対応するMEXT項目の単独候補を維持する。 |
| 乳清たんぱく・ホエイたんぱく・乳たんぱく | MEXTに個別の濃縮物・分離物の直接項目を確認できないため、脱脂粉乳のエネルギー・たんぱく質・脂質・炭水化物だけを警告付きの低信頼度fit候補として残す。食物繊維、食塩、ミネラル、ビタミン、飽和脂肪酸は値を引き継がず `null` にする。実際の脱脂粉乳の直接候補値は変えていない。 |
| 昆布 | 種類・状態が省略された表記に限り、MEXTまこんぶ素干し・乾（09017）を低信頼度の代表候補として警告付きで返す。 |
| 昆布エキス・こんぶエキス | 乾燥昆布ではなく、MEXT昆布だし水出し（17020）を液状抽出物の低信頼度代理候補として警告付きで返す。抽出濃度や状態の補正はしない。 |
| オニオンパウダー | MEXTオニオンパウダー（17056）の直接値を維持する。ローストオニオンパウダーは別候補とし、通常粉末の値を使う警告付き代理候補にする。 |
| レモン濃縮果汁・濃縮レモン果汁 | MEXTレモン果汁（07156）を未補正の警告付き代理候補として返し、直接一致扱いをやめる。[MEXT レモン果汁（07156）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=7_07156_7) |

MEXTは牛乳、全粉乳、脱脂粉乳を別項目として掲載し、粉乳については生乳等からほとんどの水分を除去した粉末と説明している。[普通牛乳（13003）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=13_13003_6)、[全粉乳（13009）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=13_13009_7)、[脱脂粉乳（13010）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=13_13010_7)、[日本食品標準成分表（八訂）増補2023年の説明](https://www.mext.go.jp/content/20230428-mxt_kagsei-mext_00001_011.pdf)

MEXTは乾燥まこんぶと水出し・煮出し昆布だしを別項目としている。エキスの直接項目はローカルのMEXT食品カタログで確認できなかったため、水出しだしは警告付き代理に限り、エキス粉末は未解決に残した。[まこんぶ素干し・乾（09017）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=9_09017_7)、[昆布だし水出し（17020）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=17_17020_6)、[昆布だし煮出し（17132）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=17_17132_7)

オニオンパウダーの直接値はMEXTの同名項目を使う。ロースト状態の独立項目は確認できないため、通常粉末を代理参照として明示する。[MEXT オニオンパウダー（17056）](https://fooddb.mext.go.jp/details/details.pl?ITEM_NO=17_17056_7)

## 見送った補完

- 濃縮りんご・ぶどう・いちご・清澄果汁は、濃縮原液と濃縮還元飲料の状態を区別できないため、直接候補や任意の濃度係数を追加しなかった。
- 「具」「衣」は構成食品・配合率が商品ごとに異なるため、一般的な料理レシピや衣材料の比率を推定しなかった。
- 「昆布エキス粉末」「こんぶエキスパウダー」は、液状の水出しだしや乾燥昆布へ寄せず未解決を維持した。
- ホエイ・乳たんぱく濃縮物／分離物のカルシウム等を脱脂粉乳値で補完しなかった。商品表示や適合する公的直接値が得られるまで欠損とする。

## 参照値の照合

明示状態の牛乳、全粉乳、脱脂粉乳、およびオニオンパウダーは、推計サービス内の手動参照値を生成済みMEXT食品データとテストで照合する。昆布・昆布エキス・ローストオニオン・濃縮レモンの代理参照も、参照先IDと栄養値が生成済みMEXT値に一致することを検証する。ただし代理先の栄養値が対象原材料を代表すると保証するものではなく、警告・曖昧状態を維持する。ホエイ等の代理は、妥当性のない対象成分を `null` にする。

一般原材料カタログの再生成は、MEXT食品データの栄養項目順を使うようにし、`PYTHONHASHSEED=1` と `PYTHONHASHSEED=42` で出力ファイルのSHA-256が同一になることを確認した。
