# 栄養素推計の必要データ収集（2026-10-06）

`nutrient_estimator_required_data.md` の優先順位に従い、未見評価候補、原材料の参照欠損、同じ基準の脂質・飽和脂肪酸表示を優先する。同文書にある過去の適格件数は今回のモデルで再評価した数ではない。既存の教師・校正・封印・prior・モデルは変更しない。

原票、商品名、原材料全文、表示値、URL対応、取得日時、利用条件、再抽出用コードはGit除外のローカル資料として保管する。公開するのは集計とhashのみ。未見候補は通常の `spu_data` と調整用データから隔離し、評価や係数調整を行わない。

## パンの同基準表示（優先順位3・4・5・6）

Warburtonsの公式サイトで20ページを調査し、19ページを保存、18行を開発用候補として取得した。1ページは404、1ページは商品別の原材料・栄養表がないため保留。全18行に主要5項目、脂質・飽和脂肪酸・食物繊維の同じ100g基準がある。表示桁と原材料欄の脚注を保持し、食塩や重量を推測で換算していない。

18行すべてについて、原HTML hash、表の列数と100g列、商品見出し、原材料欄全文、主要5項目と対象2項目を独立したDOM parserで再照合した。7行には原材料の百分率表記があり、原文と対象部分をprivate sidecarへ保存した。配合重量への換算や、強化原料・プレミックスの添加量補完は行わない。

英国向け・英語表示であるため、国内向け推計や日本語の原材料解析へ自動投入しない。系列は暫定17グループで人的審査未完。独立評価商品数には含めず、3メーカー・50件/ジャンルの条件も未達。公式利用条件で認められる個人の非商用研究保管に限定し、再配布・モデル採用の許諾を得たとは扱わない。Hovisは抽出データベースへの組み込みを制限する利用条件のため対象外とした。

保存先は `data/estimator/private/required_collection_20261006/bread_uk/`。公開集計とhashは `required_data_collection_20261006_bread.json`。

## 強化小麦粉の仕様範囲（優先順位7）

[英国政府の小麦粉組成ガイダンス](https://www.gov.uk/guidance/bread-and-flour-labelling-and-composition)から、現行4項目と2026-12-13以降の5項目を別の適用期間として保存した。基準は完成品パンではなく非全粒小麦粉100g。鉄・ナイアシン・チアミンの必要総量と、炭酸カルシウム・葉酸の添加量を区別し、上限が公表されない条件は欠損のまま保持する。炭酸カルシウムをカルシウム値へ、チアミン塩酸塩を遊離チアミン値へ読み替えない。

これは個別商品のプレミックス仕様ではない。例外、施行日、移行措置があり、取得商品の小麦粉重量や実添加量も不明なため、商品別栄養値やアプリの原材料参照値へ自動反映しない。政府ページのOGL v3.0表示、帰属文、原表の列対応を保存した。公開集計とhashは `required_data_collection_20261006_flour_specs.json`。

## 国内パンの原票（優先順位3・4）

Pascoの公式一覧と10商品ページから14表示パネルを `data/spu_data/pasco_officialSite_261006.csv` へ保存した。主要5項目、同じ表示基準の脂質と飽和脂肪酸、原材料全文、公式製品URLを保持する。枚数・入り数違いのパネルを独立系列には数えない。既存CSVの同名・同URL重複はなかった。

全14行で基準重量gが不明。平均的数値という注意書き、100g当たりのゼロ表示条件も原文のまま保存した。数値0を無条件に厳密なゼロへ変更しない。正規化CLIでは注記内の100g基準も含む `mixed_basis_panels` により全14行を保留し、採用0行。重量を推測してこの保留を回避しない。一覧・詳細栄養表・原材料全文・分類を独立抽出で全14行照合し、最終原票等31ファイルのhashも確認した。Pasco shopのPDF2ページ13商品（原票更新日2023-01-25）も私的な別資料として確認したが、明示g基準がないため同じCSVや教師候補へ混ぜない。PDFでは脂質より飽和脂肪酸が大きい表示とエネルギー単位の誤記も各1件検出し、原文保持・派生値不採用とした。

[公式栄養一覧](https://www.pasconet.co.jp/nutrition/)と[サイトポリシー](https://www.pasconet.co.jp/sitepolicy/)を確認し、個票は私的保管に限定する。変換スクリプトにPascoのメーカー・公式ホストを登録し、変換版を0.5.6へ更新した。既存の値の解析方法は変更せず、既存教師・モデル・priorの再生成も行わない。公開監査集計は `required_data_collection_20261006_pasco.json`、原票・対応表・PDF確認は `data/estimator/private/required_collection_20261006/pasco/`。
