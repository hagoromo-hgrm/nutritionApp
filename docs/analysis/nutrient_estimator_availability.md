# 栄養素推計の可用率と制約理由

- 評価日: 2026-07-30
- 対象モデル: `browser-rule-0.14.0`
- 評価データ: メーカー公式779商品、評価可能749商品、独立栄養ラベル1,551区間
- 目標: 部分参考値を含む数値提示率80%以上

## 結果

| 推計区分 | 数値提示 | 提示率 |
| --- | ---: | ---: |
| 全原材料推計 | 315 / 1,551 | 20.31% |
| 既知分部分参考値 | 383 / 1,551 | 24.69% |
| ジャンル補完参考値 | 853 / 1,551 | 55.00% |
| 合計 | 1,551 / 1,551 | **100%** |

80%ゲートは達成した。従来数値を提示できなかった7区間・3商品も、学習区分の栄養分布を全体へ縮約した低信頼度参考値として提示できるようになった。

ジャンル補完では、メーカー公式教師データの学習区分545商品だけから100g当たり5・50・95パーセンタイルを作る。既知分の点参考値は変更せず、未解決原材料または参照値欠損の重量枠を含む推定範囲にだけ事前分布を使う。数値を直接参照できる原材料がない場合だけ中央値を点参考値へ使う。低頻度、メーカー偏重、`other_unknown`は栄養素全体へ縮約し、添加物の重量枠には適用しない。

## 制約理由

1件の推計に複数理由が付くため、件数の合計は部分参考値数と一致しない。

| 理由コード | 表示名 | 該当区間 | 既知分参考値 | ジャンル補完 | 推計不可 |
| --- | --- | ---: | ---: | ---: | ---: |
| `additive_contribution_unknown` | 添加物寄与割合不明 | 770 | 340 | 430 | 0 |
| `reference_value_missing` | 参照値欠損 | 638 | 73 | 565 | 0 |
| `ingredient_unresolved` | 原材料未解決 | 615 | 0 | 615 | 0 |

### ジャンル別の主な対策場所

- `other_unknown`: 添加物寄与割合不明257、原材料未解決101、参照値欠損101。全体分布へ縮約して数値は提示するが、精度向上にはジャンル分類と参照辞書の改善が必要である。
- `dairy`: 添加物寄与割合不明148、原材料未解決135、参照値欠損92。菌液、乳由来加工原料、栄養強化規格を優先する。
- `sauce_spread`: 参照値欠損145、原材料未解決83。ソース、ペースト、濃縮原料の直接値と固形分分布を優先する。
- `chocolate`: 添加物寄与割合不明97、参照値欠損78、原材料未解決65。栄養強化商品と乳・油脂加工原料を分ける。
- `drink_jelly_pudding`: 添加物寄与割合不明107。ビタミン・ミネラル強化量を取得できない限り、通常推計率は上げない。
- `baked_sweets`: 原材料未解決86、参照値欠損76。粉末、パフ、フィリング、濃縮果汁等を優先する。

## 次の改善優先順位

1. **添加物寄与割合不明**
   - 件数が770で最大であり、ビタミンB1・B2・C、カルシウム、鉄の通常推計化を妨げている。
   - メーカー公表値、原料規格、栄養強化プレミックスの添加量範囲が必要。
   - 一律ゼロや一律添加量ではなく、栄養素・ジャンル・表示順別の候補分布を作る。
2. **参照値欠損**
   - カルシウム194、食物繊維175が大きい。
   - MEXTで欠損する項目をFDC直接値または原料メーカー仕様で補完し、形状と加工状態を一致させる。
   - 特にソース・スプレッド、乳加工原料、焼き菓子原料を優先する。現在のジャンル補完は欠損解消ではなく、広い範囲による暫定対応である。
3. **原材料未解決**
   - 数値提示不能は解消したが、全原材料推計率と精度改善には615区間が残る。
   - `other_unknown`のジャンル再分類、濃縮果汁、具・衣・たれ、ペースト、パフ、粉末、菌液を優先する。

## 精度上の境界

最終テスト219区間では、全原材料推計43区間、既知分部分参考値53区間、ジャンル補完参考値123区間の全区間へ数値を提示した。ジャンル補完参考値の点推計区間内率は21.95%、公表上限以下は82.11%、範囲重複率65.04%、MAPEは48.98%だった。全方式合計の範囲重複率は58.45%、MAPEは49.26%である。

したがって100%は「数字を提示できる率」であり、「商品全体を高精度に推計できる率」ではない。ジャンル補完は分離重量を学習した結果でも校正済み範囲でもない。手動採用、低信頼度、理由表示を維持し、実測校正から除外する。次段階では、数値提示率ではなく全原材料推計率、参照値欠損の直接解消数、ジャンル補完の独立範囲包含率を改善指標にする。
