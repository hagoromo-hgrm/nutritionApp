# 未公開

## 不具合修正

- **Myメニュー**: 複数食分で登録したレシピの「詳細」に、1食あたりのカロリーと栄養価を表示するよう修正しました。「個」「皿」などで登録した場合は、その1単位あたりを表示します。
- **メニュー管理**: 栄養価に不明・未計測の食材が含まれていても、分かっている値の小計を表示するよう修正しました。すべて不明の項目は「--.-」と表示します。
- **食事の栄養価**: メニューを食事へ登録した後も、分かっている食材の栄養価を合計して表示するよう修正しました。食事カードや確認・詳細画面、今日の集計、推移グラフに反映します。

## データ・互換性

- **栄養推計データ**: 精度検証用の資料を追加収集しました。収集した値はアプリへ自動反映していないため、表示される推計値と保存済みの食事記録に変更はありません。
