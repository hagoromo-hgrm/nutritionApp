# バージョン0.3.0

## 重要なお知らせ

- **栄養推計**: 推計値と範囲は参考情報です。今回の実商品比較では、カルシウムの平均誤差が小さくなる一方、食物繊維は大きくなりました。栄養成分表示が分かる場合は、表示値を優先して入力してください。

## 改善

- **栄養推計**: 確認済みの入力値を、他の不足項目の推計にも使うようになりました。未確認の外部値や推計値を、確認済みの栄養表示として使いません。
- **原材料の対応**: 液状乳と粉乳、乾燥卵と生卵、昆布とエキスなど、状態の異なる原材料を区別しました。対応する資料がない値は欠損のまま扱います。
- **推計範囲**: 同じ原材料候補で成立する別の配合も範囲へ反映するようになりました。表示する範囲は、実際の栄養値が必ず含まれる保証ではありません。
- **推計履歴**: 推計時に使った入力値・確認根拠・配合の情報を保存するようになりました。

## 不具合修正

- **栄養推計の採用**: 食品の確認根拠だけを変更した場合も、変更前の推計結果をそのまま採用できないよう修正しました。
- **Myセット**: 独自の食品分類を持つ外食・市販食品を選んだときも、分量と単位を指定してMyセットへ追加できるよう修正しました。

## データ・互換性

- 推計モデルを `browser-rule-0.32.0` へ更新しました。新しく実行する推計に適用し、保存済みの食品値・食事記録を自動で再計算しません。
- JSONバックアップ形式5を維持し、形式1から4も引き続き復元できます。追加した推計入力・配合・加工・添加物の確認根拠もバックアップに含めます。
- 原材料の参照には、日本食品標準成分表と状態を確認したUSDA資料を使います。食品データの自動再投入、食事履歴CSVの列・文字コードの変更、推計用の外部送信はありません。
